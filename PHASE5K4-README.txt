MarketLedger Pro V5K.4 — Signal Audit & Reason Semantics

Changes from V5K.3:
- Separates Reason type from Final status reason on the desktop Setup Board.
- Uses Confirmation for positive supporting evidence.
- Uses Caution for adverse evidence that did not prevent a positive final setup.

- Analyze now exposes 09:30 regular open, regular-session VWAP, distance from regular VWAP, and final reason type/text.
- Keeps V5K.3 exact NY trading-date session isolation.
- No scoring, BUY/STRONG thresholds, chase thresholds, liquidity thresholds, provider routing, database schema, or Signal Memory rule changes.
