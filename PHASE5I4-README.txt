MarketLedger Pro V5I.4 — Compact Board + No-Jump Analyze

UI-only follow-up to V5I.3.

Changes:
- Analyze no longer scrolls/jumps the page. It selects and refreshes the ticker and updates the existing detail section in place.
- Background analysis remains non-scrolling.
- Extended Volume board column is compact: P / A / O.
- PM Engine board column is compact: score + STRONG/SETUP/WATCH/WAIT.
- Detailed extended-volume and pre-market diagnostics remain available in the Analyze detail section.
- Existing compact Analyze control beside the ticker is retained.
- Right-side action column is tightened to reduce horizontal scrolling.

Unchanged:
- Pre-market scoring/eligibility rules.
- Regular-session thresholds.
- V5H.4 provider routing and freshness protections.
- PostgreSQL persistence.
- Outcome Engine.
- Corporate calendar.
