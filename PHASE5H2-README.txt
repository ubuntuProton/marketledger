MarketLedger Pro V5H.2 — Market Data Provider Diagnostics

Adds Render-safe diagnostics for each Alpaca market-data request.
Logs symbol, phase, feed, quote/bar HTTP status, timestamps, calculated ages, availability and FRESH/STALE/EMPTY result.
Exceptions log type/message. API keys and secrets are never logged.
No signal thresholds, persistence, calendar, or outcome-engine logic changed.
